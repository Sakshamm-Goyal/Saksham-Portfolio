# Saksham Goyal - Portfolio

A horizontal, editorial commit trail for Saksham Goyal's AI systems and full-stack engineering work.

## What is included

- AI systems positioning grounded in Saksham's current resume and public GitHub work.
- Experience across Elara, HireAnything, ASSSR (NITI Aayog), and i2V Systems.
- Seven selected builds from 96 public repositories, led by SuperOps, AI Engineering
  Planner, SAP O2C Graph Explorer, and ClipShare.
- Working horizontal navigation, responsive mobile stacking, resume download, project links, email copy action, and interactive drawing board.
- Search metadata, structured data, sitemap, robots route, and a custom social preview image.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` (or the port printed by Next.js).

## Production setup

Vercel automatically supplies the production URL used for canonical metadata. Set
`NEXT_PUBLIC_SITE_URL` only when using a custom domain or another hosting provider:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.example npm run build
```

Optional:

```bash
NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=your-verification-token
```
